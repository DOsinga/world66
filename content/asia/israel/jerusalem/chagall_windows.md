The Chagall Windows are a set of stained-glass windows by Marc Chagall in the synagogue of Hadassah Medical Center at Ein Kerem. Each window represents one of the Twelve Tribes of Israel, using Chagall's dense colour, biblical imagery, and floating figures.

The hospital setting is unusual for a major art stop, but the windows are worth the detour if you are interested in Chagall, Jewish art, or modern sacred spaces. Check visiting arrangements before going, since access can vary.
