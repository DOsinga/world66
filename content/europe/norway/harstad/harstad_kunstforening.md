Harstad Kunstforening is a local art-association gallery, useful for seeing current exhibitions and northern Norwegian creative work on a small scale. It is not a headline museum, but it can add a cultural layer to a Harstad stay.

The value depends on what is showing, so check the programme before making a special trip. For visitors already in the centre, it can be a short stop between waterfront and town sights.
