The Lake District's public observatory and planetarium, in the Yan building at the Grizedale Forest visitor centre. Evening stargazing sessions start with a talk before visitors learn to use the telescopes, and a free return visit is offered if the sky is cloudy. Daytime planetarium shows run for families and groups.
