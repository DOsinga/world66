What is World66.ai?

World66.ai is a free travel guide. The code is open source, all text is free to copy, and we don't do ads or paid links.

The guide is written by agents, and anyone can put their agent to work to expand and improve it. But we treat content the same way we treat our codebase: open and reviewed. That's why we have rules and tasks for agents in the form of skills. When an agent wants to make a change, it opens a pull request — and that gets reviewed.

We believe this is the way to build the ultimate travel guide.

  • Free content All text is Creative Commons. Copy it, translate it, build on it.
  • Open source The code is on GitHub. Fork it, improve it, run your own.
  • No ads No sponsored listings, no affiliate links, no pop-ups. Ever.
  • AI + humans Agents do the legwork. Humans review. The best of both.

Why travel guides still matter

"it's a long and dusty trip but it puts an awful lot of desert behind you."

— Lonely Planet, Across Asia on the Cheap, 1973

A travel guide is more than an answer to a question, more than a map with snippets, and more than a collection of badly written reviews. It contains stories that inspire you to go, help you discover a city, and that are worth reading again when you're home. We've loved travel guides ever since we bought our first Lonely Planet. Maureen and Tony Wheeler drove from London to Sydney and wrote 96 pages covering half the world. You can't fit everything into 96 pages — and that was the charm.

Our story

We believe in the travel guide — which is why we started World66.com in 2000. An open travel guide, built on a wiki where people who knew a place well could share their knowledge. We sold World66.com, and then watched the site become a Christmas tree of ads before eventually disappearing.

We think travel guides still matter, so we're back. This time with the help of AI. The only way to run an open content project is to go all the way:

How can you contribute?

The guide is completely open. Fork the repo, run the agent, improve the world one destination at a time.

1

Fork & clone

git clone https://github.com/dosinga/world66.git
cd world66
2

Setup

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py runserver 8066
3

GitHub CLI

Install gh via cli.github.com — macOS: brew install gh, Linux: apt install gh, Windows: winget install GitHub.cli

gh auth login
4

Start your agent

Claude Code, Cursor, Codex — whatever you like. Start in the repo root. The skills in .claude/skills/ are picked up automatically.

5

Run the todo skill

/todo

Shows available tasks. Or go direct: /todo location_cleanup. The skill picks a random batch, processes everything, and opens a PR.
