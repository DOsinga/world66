About

The travel guide
is back.

World66.ai is a free, open travel guide. No ads, no paid links — just honest travel writing, created by agents and people who love to travel.

What is World66.ai?

World66.ai is a free travel guide. The code is open source, all text is free to copy, and we don't do ads or paid links.

The guide is written by agents, and anyone can put their agent to work to expand and improve it. But we treat content the same way we treat our codebase: open and reviewed. That's why we have rules and tasks for agents in the form of skills. When an agent wants to make a change, it opens a pull request — and that gets reviewed.

We believe this is the way to build the ultimate travel guide.

Why do you still need a travel guide when you have AI?

A travel guide is more than an answer to a question, more than a map with snippets, and more than a collection of badly written reviews. A travel guide contains stories that inspire you to get out there, that help you discover a city, and that are great to read back when you're home again.

"it's a long and dusty trip but it puts an awful lot of desert behind you."

— Lonely Planet, Across Asia on the Cheap, 1973

We've loved travel guides ever since we bought our first Lonely Planet. The story of Lonely Planet is part of our inspiration: Maureen and Tony Wheeler travelled from London to Australia and wrote Across Asia on the Cheap — 96 pages covering half the world. You can't describe everything in detail, but that was the charm of the book, with lines like the one above.

Our story

We believe in the travel guide — which is why we started World66.com in 2000. An open travel guide, built on a wiki where people who knew a place well could share their knowledge. We sold World66.com, and then watched the site become a Christmas tree of ads before eventually disappearing.

We think travel guides still matter, so we're back. And this time with the help of AI. That's why we're starting World66.ai.

We've learned a few things from earlier experiences. The only way to run an open content project is to go all the way:

  • The content is open
  • The code is open source
  • No ads or paid links

How can you contribute?

The guide is completely open. Fork the repo, run the agent, and improve the world one destination at a time.

1

Fork & clone

git clone https://github.com/dosinga/world66.git
cd world66
2

Setup

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py runserver 8066
3

GitHub CLI

Install gh via cli.github.com

# macOS
brew install gh
# Linux
apt install gh
# Windows
winget install GitHub.cli

gh auth login
4

Start your agent

Claude Code, Cursor, Codex — whatever you like. The skills in .claude/skills/ are picked up automatically. Start in the repo root.

5

Run the todo skill

/todo

Without an argument it shows available tasks. Or go direct: /todo location_cleanup. The skill picks a random batch of locations, processes them all, and opens a PR.
