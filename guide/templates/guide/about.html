Wat is World66.ai?

World66.ai is een gratis reisgids. De code is open source, alle tekst mag je kopiëren en we doen geen advertenties of betaalde links.

De gids wordt geschreven door agents en iedereen kan zijn agent aan het werk zetten om de gids uit te breiden en beter te maken. Maar we benaderen de content net als onze code-base: open en gecontroleerd. Daarom hebben we spelregels en taken voor agents in de vorm van skills. En wanneer een agent iets wil wijzigen dan maakt hij een pull request aan, en die wordt gereviewd.

Wij geloven dat de manier is om de ultieme reisgids te maken.

🔒 Open source
📖 Vrije content
🚫 Geen advertenties
🤖 AI-gedreven

Waarom heb je nog een reisgids nodig als we AI hebben?

Een reisgids is meer dan een antwoord op een vraag, meer dan een kaart met snippets en meer dan een verzameling slecht geschreven reviews. Een reisgids bevat verhalen die inspireren om eropuit te gaan, die je helpen een stad te ontdekken, en die leuk zijn om terug te lezen wanneer je thuis bent.

"it's a long and dusty trip but it puts an awful lot of desert behind you."

— Lonely Planet, Across Asia on the Cheap, 1973

Wij houden van reisgidsen, sinds we onze eerste Lonely Planet kochten. Het verhaal van Lonely Planet is deel van onze inspiratie: Maureen en Tony Wheeler reisden van Londen naar Australië en schreven er Across Asia on the Cheap. 96 pagina's waarin ze de halve wereld beschrijven. Dan kan je niet alles in detail beschrijven en dat was ook de charme van het boek — zinnen als hierboven.

Ons verhaal

Wij geloven in de reisgids, daarom zijn we in 2000 World66.com gestart. Een open reisgids, op basis van een wiki waarin mensen die een plek goed kenden hun kennis konden delen. We hebben World66.com verkocht — en daarna gezien dat de site een kerstboom met advertenties werd en uiteindelijk verdween.

We denken dat reisgidsen er nog steeds toe doen, en dus zijn we terug. En nu met de hulp van AI. Daarom starten we World66.ai.

We hebben een paar dingen geleerd van eerdere ervaringen. De enige manier om een open content project te doen is wanneer je all the way gaat:

  • De content is open
  • De code is open source
  • We doen niet aan advertenties en betaalde links

Hoe kun je meedoen?

De gids is volledig open. Fork de repo, draai de agent en verbeter de wereld één bestemming tegelijk.

1

Fork & clone

git clone https://github.com/dosinga/world66.git
cd world66
2

Setup

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py runserver 8066
3

GitHub CLI

Installeer gh via cli.github.com

# macOS
brew install gh
# Linux
apt install gh
# Windows
winget install GitHub.cli

gh auth login
4

Start je agent

Claude Code, Cursor, Codex — wat je wil. De skills in .claude/skills/ worden automatisch opgepikt. Start in de repo-root.

5

Draai de todo-skill

/todo

Zonder argument toont hij beschikbare taken. Of direct: /todo location_cleanup. De skill pakt een willekeurige set locaties, verwerkt alle items, en opent een PR.
