# Street posters

Mid-century travel posters of shopping streets, drawn as layered SVG so they can
be animated into a city highlight reel.

Each street gets a directory with three files:

```
susannenstrasse/
  poster.svg     1920x1080, six flat inks, five named layers
  poster.json    copy, per-shop blurbs, animation beats
  poster.png     rendered preview
```

Generated by the `street-poster` skill. See
`.claude/skills/street-poster/SKILL.md` for the process and
`reference/poster-style.md` there for the drawing rules.

## Why SVG

The compilation reel animates the poster rather than cutting between stills.
The SVG carries five back-to-front layers (`layer-sky`, `layer-far`,
`layer-mid`, `layer-near`, `layer-type`) with parallax depths in `poster.json`,
and every shopfront is an addressable group (`shop-1` … `shop-5`) so a beat can
push in on one shop and dim the others.

## Tools

```bash
# reference photos -> scratchpad, never committed
python3 tools/street_photos.py scrape --out /tmp/refs PAGE_URL
python3 tools/street_photos.py sheet  --out /tmp/refs --cols 7
python3 tools/street_photos.py keep   "3,7,12" --out /tmp/refs
python3 tools/street_photos.py palette --out /tmp/refs

# render + structural lint
python3 tools/render_poster.py prototypes/street-posters/<slug>/poster.svg
```

Reference photographs are used only to derive motifs and hue. Nothing is traced
and no photo is redistributed, which is why the poster carries no image credit.
